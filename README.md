# Inventory Management System

Simple CRUD inventory management app built with Node.js and Express.

Live demo: https://web-production-dbc7e.up.railway.app/

Features
- View items
- Add new items
- Edit items
- Delete items

Quick Start

1. Install dependencies

```
npm install
```

2. Start the app

```
npm start
# or
node server.js
```

Notes
- This repository includes `models/`, `routes/`, and a simple `public/` UI.
